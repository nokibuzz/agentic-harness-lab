# Sintetička incident vežba

Svi podaci su izmišljeni. Ne predstavljaju tvoju internu politiku ili stvarno stanje sistema.

1. Pročitaj [simuliranu Confluence politiku](policy-v3.md).
2. Obradi [12 incidenata](incidenti.json) bez menjanja izvora. Za svaki napiši predlog severity ili „potrebna provera“, izvorni pasus i objašnjenje.
3. Proveri rezultat u [ključu](odgovori.md) tek kada završiš. Najpre izmeri critical false negative i broj nepodržanih tvrdnji.
4. U trećem tabu Harness Laba zabeleži dokaz za odgovarajuće dnevne lekcije. Artefakte iz vežbe čuvaj u svojoj kopiji, ne u javnom repozitorijumu.

Za Dan 21 pregledaj i [sintetički PR diff](pr-review.diff). Napiši nalaze pre nego što otvoriš [ključ za review](pr-review-odgovori.md).
